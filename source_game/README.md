# Tiên Môn Linh Vận — project Godot

Đây là source project của bản ổn định trước revision Google Doc ngày 2026-10-19. Mở `project.godot` bằng Godot 4.7.2.

Hướng dẫn đầy đủ để build HTML5 và chạy server nằm trong `../README.md` ở thư mục gốc gói.

Thư mục `.godot/` không được lưu trong gói vì chỉ chứa cache editor; Godot sẽ tạo lại khi mở/import project.
